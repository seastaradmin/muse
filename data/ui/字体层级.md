# 定义

字体层级（type scale / 类型尺度）是界面中一组大小、字重有序递进的字号集合，用于区分标题、副标题、正文、注释等不同层级，让阅读顺序清晰。它与排版、视觉层级配合，是界面"信息主次"在文字上的落地。

# 核心要点

- **成比例递进**：字号按固定比例递增（如 1.25×、1.333× 的模数尺度），而不是随意取 13/15/18。
- **有限档位**：通常 3-5 档即可（显示/标题/副标题/正文/注释），档位过多则层级混乱。
- **语义化 token**：把字号命名为 type-2xl、type-base、type-sm 等 token，避免裸数值。
- **字重辅助**：靠字号 + 字重（如正文 400、标题 600/700）共同拉开层次，不必全靠字号硬撑。
- **与行距匹配**：大字号行距相应放宽，小字号行距收紧，保持整体可读（见 [[排版]]）。

# 适用范围

- **UI/前端**：页面标题、卡片标题、正文、按钮、标签、注释的字号规范。
- 排版、海报、文档的层级设计（通用场景）。

# 常见误区

- 字号随意堆叠、没有比例 → 层级含糊、观感杂乱。
- 档位过多，14 与 15 之间细微差别无意义。
- 只靠字号区分层级，字重/颜色/留白没有配合。
- 大标题行距过紧、小字行距过松，破坏可读性。
