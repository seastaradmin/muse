# 构图评审要点

评审画面/镜头时，检查主体安排、视线引导、比例与平衡。

## 与「视觉层级」的分界
构图管「元素摆在哪、怎么排」——位置、对齐、网格、整幅画面的平衡与留白；视觉层级管「哪个元素最突出、按什么顺序被看到」——大小/颜色/对比制造的主次。
两者可同高或同低：如元素都居中偏左（构图分低）但重点仍清晰（层级分可高）；又如平铺但整齐（构图分可高、层级分低）。打分时先看「位置与平衡」，再看「主次与引导」，避免混为一谈。

## 看什么
- 主体在画面的什么位置？是否自然、有动势？
- 地平线/分割线放在哪里？是三分线还是正中？
- 人物/主体的视线或运动方向留了空间吗？
- 比例关系（黄金比例、三分）是否带来平衡与美感？

## 好看的标准
- 主体放在三分交叉点或略有偏移，比居中更自然耐看（有意对称除外）。
- 分割线放在上/下三分之一处，避免画面被一刀切成两半。
- 视线/运动方向一侧留有负空间，画面"透气"、不堵。
- 平衡而不呆板：各元素重量大致均衡，或有意制造偏斜的张力。

## 常见错误
- 主体永远正中央 → 呆板、缺动势。
- 地平线居中一刀切 → 生硬。
- 视线方向空间不足 → 画面"堵"、压抑。
- 把三分法当铁律硬套 → 破坏特殊构图的需要。

## 功能型界面豁免
工具/工作台类 UI（仪表盘、编辑器、后台）的构图求稳不求巧：以**对齐、网格、区域划分、信息密度分布**为主要评判依据；三分法等摄影构图法则仅作参考，不因"主体未偏移三分点"而扣分。

## 打分参考（1-10）
- 8-10：主体安排自然有张力，比例平衡，负空间得当。
- 5-7：主体合理但偏居中或略显呆板。
- 3-4：主体位置别扭、画面失衡或分割生硬。
- 1-2：无明确主体、构图混乱。

## 依据与出处
- **语料支撑**：三分法（九宫格、交叉点、地平线放三分线）—— 维基《三分法》(zh)；黄金比例 —— 维基《黄金比例》(zh)："应用时一般取1.618"；视线方向留空间（lead room）—— 维基《构图》(zh)。
- **评审约定**（非美学知识）：与视觉层级的分界、功能型界面豁免 —— 本 skill 的打分操作约定。
