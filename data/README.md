# Muse 数据面

美学鉴赏 Agent 的数据地基。先建数据，再建理论，最后建 Agent。

## 结构（倒三角）

```
data/
  _raw/           采集原料（脚本只写这里）—— 待清洗的全文
    principles/   原理层原料
  principles/     通用审美原理层（清洗成品）—— 两个项目共用，优先级最高
  ui/             前端 UI 美学层（后续）
  cinema/         短剧/影视美学层（后续）
  foundation/     艺术史 + 经典美学理论层（原理溯源，后续）
```

> **信源本体是 HTML**：`_raw/` 里每篇有三种文件——
> - `<标题>.html`　渲染好的**正文**，浏览器打开即看（含在线图片、排版）✅ 主看这个
> - `<标题>.full.html`　整页原始 HTML（备份）
> - `<标题>.md`　纯文本全文（将来喂模型用）
>
> 采集脚本只写 `_raw/`，绝不覆盖 `principles/` 里的成品。

## 语言与命名规范

- **正文**：以中文为主。英文源拉取的资料，中文条目优先落地，英文素材留作后续翻译。
- **文件名**：`中文名`（如 `色彩理论.html`）。中文维基缺页时回退英文内容，但文件名仍用中文。

## 怎么看知识库

直接浏览器打开 `data/_raw/principles/<分类>/<标题>.html` 即可（带图片）。快速浏览：

```bash
open data/_raw/principles/color/色彩理论.html
```

> 图片为在线加载（引用维基原图 URL），需联网。若要离线，后续再加图片下载。

## 条目格式

`principles/` 下是可选的精编卡片（Markdown，带 frontmatter + 固定小节），见 [`_schema.md`](principles/_schema.md)。
**注意：卡片式清洗不是必需**——若目标是"攒一个能读、能喂模型的审美知识库"，`_raw/` 里的 HTML/文本已足够；卡片只在想做人读的精编条目时再做。
