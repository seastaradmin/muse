# 定义

设计语言一致性（design consistency）是指界面在视觉与交互上使用一套统一、可复用的规则——颜色、间距、字体、圆角、阴影、组件样式在全局保持一致。它让产品看起来专业、可信，也让用户能预测交互。

# 核心要点

- **统一 token**：颜色、间距、字体、圆角、阴影等用统一的设计 token，一处定义、全局复用，杜绝"同元素不同样"。
- **组件一致**：同类组件（按钮、输入框、卡片）在全局样式一致，不只靠复制粘贴。
- **色系一致**：主色/辅色/强调色/状态色全局统一（见 [[色彩理论]]），不随页面随意改。
- **层级一致**：标题/正文/注释的样式全局一致（见 [[视觉层级]]）。
- **圆角/阴影一致**：圆角半径、阴影强度有统一档位，避免圆角忽大忽小、阴影忽重忽轻。

# 适用范围

- **UI/前端**：产品全局、组件库、设计系统、多页面项目。
- 多端一致（Web/移动端）的规范统一。

# 常见误区

- 同一元素在不同页面样式不同 → 观感不专业、显"拼接感"。
- 每页各自定义颜色/间距，没有统一 token → 无法维护。
- 过度一致导致单调，失去必要的差异化（见 [[比例/平衡/统一]] 的"统一中有变化"）。
- 只统一视觉，忽略交互状态（配合 [[组件状态]]）。
