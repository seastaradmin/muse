# 定义

色彩理论是关于色彩如何被感知、组合与和谐的体系。它回答"哪些颜色放在一起好看"，是绘画、UI 设计、影视调色共用的底层工具。

# 核心要点

- **色相**：颜色的种类（红、蓝、绿…），是区分不同颜色的根本属性。
- **饱和度**：颜色的鲜艳/灰浊程度，高饱和醒目、低饱和柔和沉稳。
- **明度**：颜色的明暗，决定画面/界面的明暗层级与可读性。
- **色轮**：12 色色轮是配色的基础工具，用于判断颜色关系（同类、邻近、互补）。
- **常见配色关系**：
  - 同类色（单色系）：和谐、易显单调，靠明度/饱和度变化拉开层次。
  - 邻近色：柔和统一，视觉舒适。
  - 互补色（色轮相对）：对比强烈、冲突明显，需控制面积与明度避免刺眼。
  - 三角色/分裂互补：均衡而丰富。
- **配色比例**（经验法则）：大致 60/30/10 —— 主色、辅色、强调色，让画面有主次而不混乱。
- **色彩心理**：颜色会唤起情绪（蓝=冷静、红=兴奋、绿=自然），用于传达情感倾向。

# 适用范围

- **通用**：绘画、摄影、平面。
- **UI**：品牌色、主/辅/强调色、暗/亮模式、状态色（成功/警告/错误）。
- **影视**：场景氛围、人物情绪、统一色调（color palette）。

# 常见误区

- 颜色堆太多、没有主次 → 用 60/30/10 控制，或限制为单一主色 + 少量强调色。
- 互补色等面积硬怼 → 对比过强刺眼，应拉开明度或缩小一方面积。
- 忽略可读性：文字与背景对比不足 → 保证文字与底色的明度/对比足够。
- 只看色相、忽略饱和度和明度 → 同一色相不同明暗也能构成层次。
