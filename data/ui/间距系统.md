# 定义

间距系统（spacing system）是界面中统一、有层级地安排元素间距的规则体系。它用一套有限的、成比例的间距值（间距 token），代替随意的 px，让整个界面的留白节奏一致、可预测。

# 核心要点

- **固定基准尺度**：常用 4pt 或 8pt 基准，所有间距取基准的整数倍（4/8/12/16/24/32/48…），避免 6、7、13 这类"任意值"。
- **间距 token**：把常用间距命名成语义化层级（如 space-2=8px、space-4=16px…），使用时引用 token 而非裸数字。
- **成体系的间距尺度**：典型如 4、8、12、16、24、32、48、64，覆盖紧凑到宽松。
- **分组关联**：相关元素间距小、不相关的大——通过间距表达分组关系，比用边框更干净。
- **与留白配合**：间距系统是留白在 UI 里的落地形式（见 [[留白与负空间]]），透气感来自统一的间距节奏。

# 适用范围

- **UI/前端**：所有组件内外间距、卡片、列表、表单、页面边距。
- 组件库 / 设计系统（与 [[设计语言一致性]] 配套）。

# 常见误区

- 间距随意、处处不同 → 界面显得毛糙、没体系。
- 用边框/分隔线代替间距来表达分组，反而增加视觉噪声。
- 间距 token 层级过多（几十个），失去了"有限可预测"的意义。
- 只设内边距忽略外边距，或反之，导致对齐失衡。

# 依据与出处

- **体系规范（Material）**：Material 3 间距用 **4dp 栅格 / 8dp 基准**，density 控制紧凑度（m3.material.io/foundations/spacing），见 [[Material设计体系]]。
- 手工精编：UI 设计惯例（8pt 网格、间距 token、语义化间距），语料层尚无专门维基条目；与之关联的通用原理见 data/principles/space。
