# 定义

组件状态（component states）是交互组件在不同情形下的视觉表现——默认、悬停、按下、聚焦、禁用、加载、错误等。为每个状态设计清晰、一致的视觉反馈，是界面可用性与专业感的关键。

# 核心要点

- **常见状态集**：default（默认）、hover（悬停）、active/pressed（按下）、focus（聚焦）、disabled（禁用）、loading（加载）、error（错误）、selected（选中）。
- **状态可辨识**：状态变化要明显但不过度——如 hover 用轻微加深/提亮、加阴影，focus 用焦点环（focus ring）。
- **禁用态弱化**：disabled 用低对比、低饱和呈现，但文字仍须可读（对比度见 color.md）。
- **状态一致**：同一组件在所有位置的状态表现一致（配合 [[设计语言一致性]]）。
- **颜色语义一致**：成功/警告/错误用统一状态色，不随页面变化。

# 适用范围

- **UI/前端**：按钮、输入框、下拉、开关、链接等交互组件。
- 交互反馈的可访问性：聚焦态尤其对键盘/无障碍用户重要。

# 常见误区

- 只有 hover，忽略 focus → 键盘用户无法辨识焦点。
- 状态变化过小，用户察觉不到点击反馈。
- disabled 用色对比过低 → 不可读。
- 不同页面/组件状态样式不统一 → 用户困惑。

# 依据与出处

- **体系规范（Material）**：Material 3 每个组件定义 enabled、hovered、focused、pressed、dragged、disabled 等状态，统一用状态 token（如 focus 焦点环）（m3.material.io/styles/state 与组件状态章节），见 [[Material设计体系]]。
