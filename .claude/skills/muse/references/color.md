# 色彩评审要点

评审画面/界面时，检查色彩是否和谐、有主次、可读、传达恰当情绪。

## 看什么
- 用了哪些颜色？主色、辅色、强调色各是什么？
- 饱和度与明度分布如何？是否层次清晰？
- 文字/前景与背景的对比是否足够（可读性）？
- 颜色传递的情绪是否贴合内容主题？

## 好看的标准
- 有明确主色，配色有主次，不杂乱（经验比例约 60% 主色 / 30% 辅色 / 10% 强调色）。
- 对比足够但不过度刺眼：互补色若同时出现，用面积或明度拉开冲突。
- **可读性硬阈值（WCAG 2.1 AA）**：正文文字与背景对比度 ≥ **4.5:1**，大号文字（≥18pt 或 14pt 加粗）≥ **3:1**。低于此即判定可读性不达标，不靠"感觉"。
- 同类/邻近色带来和谐统一；明暗拉开层次。
- 色彩服务于情感与信息，不喧宾夺主。

## 常见错误
- 颜色堆太多、没有主次 → 画面/界面杂乱。
- 互补色等面积硬怼 → 刺眼、冲突。
- 前景背景对比不足 → 可读性差。
- 只看色相、忽略饱和度和明度 → 层次丢失。

## 打分参考（1-10）
- 8-10：有主次的和谐配色，对比恰当前可读性好，色彩强化主题。
- 5-7：整体和谐但略平、或个别颜色搭配生硬。
- 3-4：颜色杂乱、对比失衡、可读性受损。
- 1-2：严重配色混乱，几乎无可读性。

## 依据与出处
- **语料支撑（硬阈值）**：对比度 ≥4.5:1（大字 ≥3:1）—— **WCAG 2.1 AA 可读性标准**，官方可引用规范（https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum.html）。
- **语料支撑**：色相/饱和度/明度三属性、色轮、同类/邻近/互补/三角色关系 —— 维基《色彩理论》(en)、《配色》(zh)、《色彩和谐》(en)。
- **精编卡**：互补色需拉开明度或面积、前景背景对比保可读 —— 项目精编卡《色彩理论》。
- **经验值**（语料未收，引用须注明）：60/30/10 配色比例 —— 设计行业惯例，非语料结论。
