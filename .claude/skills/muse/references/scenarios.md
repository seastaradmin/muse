# 场景画像路由（先定场景，再评审）

评审第二步（在读图定类型之后）确定**场景画像**：从截图视觉特征自动匹配下方场景，据此调整维度权重、锚定设计体系、并给出**动态/自适应建议**。场景画像决定"用什么尺子、重点看什么、建议往哪个方向"，不改变"通用美学=交叉验证非裁决"的底线。

> 若画面可同时归多个场景（如"电商落地页"同时像落地页与电商），按**主导目的**选一个：页面主推销售选电商、主做品牌表达选落地页、内容为主选内容。无法归类或拿不准时退回「非 UI 图像」或用现有通用 6 维。

## 路由表（截图特征 → 场景）

| 场景 | 判定信号（截图里看到什么） | 高权维度 | 设计锚点 | 气质 |
|---|---|---|---|---|
| **写作工具/文本类** | 以编辑/书写区为主、大量空白、文字为主、低干扰、可能有光标/工具栏 | 留白、排版、平衡 | 中国美学（意境/气韵/留白） | 静谧、专注、沉浸 |
| **落地页/营销页** | 单一长页、首屏 hero（大标题+CTA）、导航栏、分区块、营销文案 | 层级、构图、排版 | Material + 反 slop（taste 工艺） | 传达价值、有记忆点 |
| **仪表盘/数据** | 卡片/表格/图表、数据密集、侧边栏导航、指标数字 | 层级、色彩（对比）、构图 | Material | 清晰、高效、可信 |
| **电商/商业** | 商品图/价格/按钮(加购/购买)、多商品陈列 | 色彩、构图、层级 | Material | 转化导向、品质感 |
| **作品集/创意** | 大量图像/作品展示、个性化排版、实验性布局 | 构图、留白、排版 | 表现力（非单一体系） | 有个人风格、有张力 |
| **内容/编辑/博客** | 长文阅读、段落+标题、正文为主、可能是衬线字体 | 排版、留白、层级 | 编辑型排版 | 易读、优雅 |
| **工具类 App** | 表单/设置/操作区、明确组件（按钮/输入/开关）、功能界面 | 层级、色彩（状态）、构图 | Material | 清晰、反馈明确 |
| **非 UI 图像** | 非界面（摄影/画作/海报/短剧帧） | 构图、色彩、留白 | 通用美学（无 UI 体系） | 看画面自身 |

## 场景画像明细

### 1. 写作工具 / 文本类产品（优先）

- **判定信号**：画面主体是书写/编辑区，文字量大且以空白衬托；通常低色彩、低干扰；可能有光标、行号、工具栏、边栏。
- **维度权重**：留白 ↑↑、排版 ↑↑、平衡 ↑；色彩 ↑（克制很重要，色过多即破坏专注）；构图/层级中。
- **设计锚点**：**中国美学**——意境（情与景融、虚实相生、留想象空间）、气韵（整体贯通、有"活气"）、留白（以无胜有）。氛围目标是**静谧专注的沉浸感**，不是视觉炫技。
- **美学气质**：沉静、呼吸感、让人安心落笔；大留白是特征不是空洞，排版层级是唯一主角。
- **动态建议主题**：文字动效克制（光标、光标随打字呼吸、淡入即可，勿抢戏）；配色建议走「neutral/tonal 动态方案」保持沉静；明暗自适应（写作工具常在弱光/深色模式使用）。
- **常见误区**：把"留白多"误判为空洞（该场景下是优点）；用强对比色破坏专注；动效过度（打字机、粒子背景）喧宾夺主。

> **精编卡说明**：本画像的美学气质提炼自 `data/foundation/` 的《意境》《气韵》《中国美学》三张卡（谢赫六法"气韵生动"、王国维"境界说"、以无胜有）；留白维度见 [space.md](space.md)。

---

### 2. 落地页 / 营销页

- **判定信号**：单页营销结构——顶部导航 + 首屏 hero（大标题 + 一句副文案 + 1-2 个 CTA）+ 依次的卖点/特性/证据区；文案驱动。
- **维度权重**：层级 ↑↑（第一屏价值主张必须第一眼看到）、构图 ↑、排版 ↑；留白中。
- **设计锚点**：Material（可访问性/对比）+ **反 slop 工艺**（与 taste-skill 同源——详见「联动钩子」）。
- **美学气质**：第一屏即传达"我是谁、为我何来"，有记忆点、不像模板。
- **动态建议主题**：hero 纪律（标题≤2 行、副文案≤20 词、CTA 不折叠）；对比度硬阈值（WCAG）；配色用「baseline/tonal」并统一一个强调色、锁定全局；明暗自适应。
- **常见误区**：三张等宽特性卡、居中 hero + 暗色网格、Inter 默认、处处微动效（均为 AI 模板特征）。

> **联动钩子（暂不接入）**：落地页是 taste-skill 的主场。后续可做"taste 执行生成 / 打磨 → muse 评审"的并行双审；当前本画像只引用与 taste 同源的反 slop 工艺判据，不执行 taste。

---

### 3. 仪表盘 / 数据产品

- **判定信号**：数据密集——表格、图表、卡片、指标数字、常配侧边栏/筛选器；信息量大。
- **维度权重**：层级 ↑↑（谁先被看到=哪个指标最重要）、色彩 ↑（用色区分类别/状态，对比要够）、构图中；留白/排版中。
- **设计锚点**：Material（elevation、组件状态、tonal 调色板、非文本对比）。
- **美学气质**：清晰、高效、可信；数据是主角，视觉服务阅读。
- **动态建议主题**：非文本组件边界对比 ≥3:1（WCAG）；图表配色考虑色觉障碍（红绿之外加形状/纹理）；密度用 8dp 体系；配色走「baseline」保证可读、避免高饱和把数据搞乱。
- **常见误区**：处处强调=没有强调（层级平）；图表颜色高饱和刺眼；红绿单靠颜色传达状态。

---

### 4. 电商 / 商业

- **判定信号**：商品图、价格、购买按钮（加购/立即购买）、多商品/多品项陈列、促销元素。
- **维度权重**：色彩 ↑↑（产品与背景分离、CTA 突出）、构图 ↑（陈列节奏）、层级 ↑；留白/排版中。
- **设计锚点**：Material（按钮对比、组件状态、间距栅格）。
- **美学气质**：品质感 + 转化导向；产品图是主角，CTA 一眼可见。
- **动态建议主题**：CTA 按钮对比硬阈值（白底白字/透明无边框都禁）；产品图留白、背景统一；明暗自适应下保证商品图与卡片分离。
- **常见误区**：CTA 与背景对比不足；商品密集无节奏；色块过杂抢产品本身。

---

### 5. 作品集 / 创意

- **判定信号**：以图像/作品展示为主、排版个性化/实验性、可能不对称、留白大但布局"有设计感"。
- **维度权重**：构图 ↑↑、留白 ↑、排版 ↑；色彩/层级中（取决于作品）。
- **设计锚点**：表现力——尊重个人风格，不套单一体系（风格相对性最强）。
- **美学气质**：有个人辨识度、有张力；"统一中的变化"在此最要紧，避免呆板或堆砌。
- **动态建议主题**：构图可用高 variance（不对称、比例变化）；动效可更丰富但须"有动机"；配色可更大胆（可走「vibrant」）；仍保可读性与整体平衡。
- **常见误区**：用通用美学把个性设计"摁死"；或反之过度堆砌失去统一。此场景最需「风格相对性」尺子（见 domains.md）。

---

### 6. 内容 / 编辑 / 博客

- **判定信号**：长文阅读——多段落正文 + 标题层级，可能是衬线字体，版心窄、留白多。
- **维度权重**：排版 ↑↑（行长、字号层级、行距）、留白 ↑、层级 ↑；色彩/构图中。
- **设计锚点**：编辑型排版（typography 优先）。
- **美学气质**：易读、优雅、安静；正文是主角，排版服务阅读。
- **动态建议主题**：行长 45-75 字符（中文 30-45 字）；字号层级清晰；衬线/无衬线的选择要克制；对比度硬阈值；明暗自适应（阅读常在深色模式）。
- **常见误区**：行长过长/过短、层级不清、字体混用、为装饰牺牲可读性。

---

### 7. 工具类 App

- **判定信号**：表单、设置、操作区，明确组件（按钮/输入框/开关/列表），功能界面而非展示页。
- **维度权重**：层级 ↑↑、色彩（状态）↑、构图中；留白/排版中。
- **设计锚点**：Material（组件状态 enabled/hover/focus/pressed、间距栅格、反馈）。
- **美学气质**：清晰、反馈明确、可信；功能可用性优先于炫技。
- **动态建议主题**：组件状态齐全（focus 焦点环、disabled、hover）；输入/按钮对比硬阈值；间距成体系（8dp）；配色走「baseline」稳。
- **常见误区**：只有静态成功态、缺 loading/空/错误态；间距不一；focus 态缺失（可访问性）。

---

### 8. 非 UI 图像

- **判定信号**：非界面——摄影、画作、海报、短剧帧。
- **维度权重**：构图、色彩、留白（按画面类型，见 domains.md 表）。
- **设计锚点**：通用美学（无 UI 体系，不套 Material）。
- **美学气质**：看画面自身，尊重流派（极简/波普/印象派…）。
- **动态建议主题**：无 UI 动态建议；按通用 6 维评审，风格相对性优先。

## 依据与出处

- 本文件为**评审约定**（skill 的运行时操作规则），非美学知识结论；其中落地页/仪表盘/电商/工具类的工艺判据（hero 纪律、非文本对比≥3:1、组件状态、间距栅格）与 **Material Design 3 官方规范**一致（见 [material.md](material.md)、[dynamic.md](dynamic.md)），写作工具的美学气质为**精编卡**（见上第 1 画像）。
- 动态配色/自适应建议的官方依据见 [dynamic.md](dynamic.md)。
