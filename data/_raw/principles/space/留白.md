# 原文（全文，待清洗）

留白（又稱餘白或布白），是中國藝術的重要技法與美學觀念，常見於水墨畫。字面意為「留下空白」，指在創作中刻意保留未施筆墨的空白處。最初可能只是無意的構圖手法，用以襯托主體，後來逐漸演變成營造意境、調和虛實、賦予作品想像空間的核心美學原則。這種「以無勝有」、「以虛襯實」的藝術思維，深植於中國哲學的道家與禪宗思想，並在日本美術中以「餘白」的概念傳承發展。


== 概念與源流 ==
在中國藝術中，留白不是單純的空白或未完成，而是一種經過精心安排的「虛」的佈局。有別於西方傳統繪畫傾向填滿畫布的「空間恐懼感」，中國畫家將空白視為畫面的必要組成，認為「無畫處皆成妙境」。
從物理層面看，水墨畫的留白與其媒材特性密切相關。與西方油畫顏料覆蓋畫布表面不同，水墨會滲入宣紙或絹的纖維中，形成筆墨與載體相互滲透、彼此融合的「相入」狀態。因此，畫面上的空白並非「無物」的背景，而是與筆墨處於同一層次、共同構成畫面的有機部分。這種特性使得留白能自然轉化為雲、水、霧氣或光線，實現「墨紙相融為主題」的表現手法，例如直接以絹本的白色來表現月亮或積雪。
留白技法的發展歷史悠久。早期如六朝畫家顧愷之的人物畫中，留白常無意識地用於省略背景，以突出主體人物。經過唐、宋等朝代發展，尤其在山水畫鼎盛時期，留白從構圖技巧昇華為創作的核心美學原則。它不僅用以表現天空、流水、雲霧等難以具體描繪的自然景物，更是分割畫面、調和虛實、創造節奏與韻律感的關鍵。透過留白，畫家能在有限畫幅中營造無限的空間感與深遠意境，達到「象外之象，景外之景」的藝術效果，使畫面氣韻生動。


== 繪畫中的技法與表現 ==

中國山水畫在宋朝達到高峰，而北宋與南宋在留白運用上各有特色。北宋山水畫多為全景式構圖，山勢雄偉，畫面飽滿；南宋畫家則更偏好邊角式構圖，畫面常有雲霧繚繞、水天一色的景象，更注重以留白營造「意境」之美。留白技法依其功能，可大致分為以下幾類。


=== 山石留白 ===
山石留白是在山體、岩石結構周圍或內部留下空白，以表現雲霧、嵐氣或光線，從而「以虛塑實」。南宋畫家馬遠的《踏歌圖》即為佳例。畫中近景人物樹石描繪細緻，中段山腰與遠景山峰則被大片雲霧（留白）環繞、遮掩，產生虛實相生的效果。這片留白不僅突顯主峰的高聳，更化解了實體山石的沉重感，使畫面產生呼吸感與層次感，反映了文人對超脫塵世、寧靜致遠境界的嚮往。


=== 水天留白 ===
水天留白是在畫面中以大面積空白表現江、河、湖、海等水域或天空。這種留白看似空無一物，實則意蘊深遠。馬遠的《寒江獨釣圖》是此技法的典範。畫中除一葉扁舟與獨釣漁翁外，絕大部分皆為空白。這片廣闊的留白既是寒江，也是瀰漫的霧氣，模糊了天與水的邊界。觀者能從中感受到江水的浩渺無垠與清冷靜寂，畫家不著一墨，依然將唐朝詩人柳宗元《江雪》的詩意完美呈現。同樣，元代畫家黃公望的《富春山居圖》長卷，也善用留白，以大片空白化為煙波浩渺的江水，使水天相接，畫境得以延展，氣韻貫通全篇。


=== 惜墨與減筆 ===
「惜墨如金」是中國畫論的重要觀念，指畫家在創作中極度節制用墨，追求以最少筆墨表達最豐富內涵。這種技法不僅擴大了畫面的留白，更體現了「計白當黑」的佈局巧思，將空白視為構圖的實體部分，藉此引導觀者產生豐富的聯想。
南宋畫家梁楷被譽為「惜墨如金」，其開創的「減筆體」畫風即是典範。在他的《李白行吟圖》中，人物衣袍以寥寥數筆、靈動肆意的線條勾勒而成，四周留有大量空白。此處的留白不僅突顯了李白仙風道骨般的氣韻，更營造出詩人且行且吟、飄逸灑脫的意境，寓人以無盡的聯想空間。這種對筆墨的極致省略，將詮釋權完全交給觀者，是留白藝術中一種更為凝練的表現。


=== 意境留白 ===
留白的最高境界在於營造「意境」，即「畫外之象」，讓觀者產生超越畫面的聯想。近代畫家齊白石的《蛙聲十里出山泉》是絕妙例子。畫中並未畫出任何青蛙，僅畫了幾隻蝌蚪在湍急的山泉中奮力游動。畫面大部分為留白，代表了廣闊的水域和遠處的山澗。觀者通過游動的蝌蚪，便能聯想到它們的母親——青蛙，並彷彿能聽到從十里之外傳來的陣陣蛙鳴。此處的留白不僅帶來視覺衝擊，更激發觀者的想像力，最終在聽覺上獲得滿足，達到了「詩中有畫，畫中有詩」的境界。


=== 為題跋留白 ===
自宋、元以後，文人畫興起，詩、書、畫、印相結合成為風尚。畫家在創作時，會有意在畫面上留下大塊空白，為自己或後來的鑑賞家題寫詩文、題跋提供空間。明朝畫家徐渭的《水墨葡萄圖》便是典型。畫家僅用淋漓的筆墨畫出垂落的葡萄藤，畫面的上半部及左側則是大片留白。徐渭在此以其奔放的行草書題詩，抒發一生坎坷的悲憤。原本空疏的畫面，因題跋書法的加入而變得完整，書法的線條與畫中的藤蔓相互呼應，內容與畫意相得益彰，極大地豐富了作品的內涵與藝術張力。


== 日本美術中的餘白 ==
在日本美術中，餘白（日語：余白／よはく，羅馬化：yohaku）是核心的美學觀念，深刻影響水墨畫、大和繪乃至現代設計。值得注意的是，「餘白」作為明確的美學術語，其歷史並不久遠。它是在明治時代日本藝術界與西方油畫接觸、對比的過程中，被重新「發現」並賦予了象徵東洋或日本獨特美感的地位。
餘白在日本畫中具有多重功能。首先，它作為「間」（日語：間／ま，羅馬化：ma）發揮作用，即物體之間的空間，用以調節構圖的節奏與平衡。例如狩野探幽繪製的障壁画（襖繪），其對物體位置的精準安排，正是透過大面積的餘白來營造物體間的呼應關係。其次，餘白可以是「無限定的空間」，它不被視為平面的白色，而是引導觀者視線、暗示無限深遠的抽象空間。

餘白在日本的發展，與15世紀盛行的「詩畫軸」關係密切。當時畫家為預留題寫漢詩的空間，常將景物安排在畫面下方，形成上方大面積空白。隨著時代演變，即使詩文被省略，這種上方留白的構圖也被繼承下來，逐漸成為自覺的美學追求。此外，受禪宗思想影響，「惜墨」觀念也推動餘白的運用。畫家透過極度節制筆墨，如南宋梁楷的「減筆體」，來突顯筆墨與餘白之間的張力。這種追求甚至發展至極致的「罔兩畫」（日語：罔両画／もうりょうが，羅馬化：mōryōga），以極淡墨色作画，使形象本身趨近餘白，探討存在與虛無的邊界。


== 哲學意涵 ==
留白不僅是藝術技巧，更是中國哲學思想在視覺藝術上的體現，其核心在於「虛實相生」的辯證思維。道家思想是其重要理論基礎，老子在《道德經》中提出「有無相生」，認為「有」與「無」、「虛」與「實」是相互依存、相互轉化的。留白正是這一思想的具體體現：畫面中的「實」（筆墨所繪之景）因「虛」（空白）而顯得突出，而「虛」也因「實」的存在而具有意義和內涵。莊子所言的「虛室生白，吉祥止止」，也強調了「虛」能生發萬物、匯聚精神的境界，這與留白賦予觀者想像空間的功能不謀而合。
同時，佛教禪宗的「色即是空」思想對留白的影響尤為深遠。「色」指一切有形的物質現象，「空」則指其非永恆、無自性的本質。在繪畫中，「色」可理解為筆墨所及之處，而「空」即是留白，兩者互為緣起。畫家透過留白，表達了對萬物本質的洞察，追求一種超越形似的空靈、靜寂之美。這種「不立文字，教外別傳」的禪宗精神，與留白「不著一字，盡得風流」的藝術追求高度契合。
此外，留白也暗合儒家的「中庸之道」與「和」的美學觀。過於飽滿或過於空疏的構圖都被視為偏頗，而留白正是調節畫面虛實、疏密、輕重，使其達到均衡、和諧的手段，體現了儒家所追求的溫潤、含蓄之美。


== 科學分析 ==
從知覺心理學的角度看，「留白」並非畫面上所有未描繪的區域。有科學研究發現，觀者在感知留白時，通常會將其認定為離物體和畫框有一定距離的區域；緊鄰物體或畫框的空白地帶，則不被視為餘白。該研究提出一個基於「場地理論」的計算模型，認為物體與畫框會對畫面產生一種知覺上的「影響力」，而餘白正是這股影響力衰減到特定閾值以下的區域。
然而，在複雜的繪畫作品中，留白的感知還受到更多高層次因素的影響，導致簡單的空間模型無法完全解釋。這些因素揭示了餘白感知的複雜性：例如，相較於物體上方，其下方的空白區域較不易被感知為留，特別是當下方空間暗示著地面或水平面時，這種位置上的不對稱性影響了判斷。此外，被物體（如樹枝、山石）所包圍或半包圍的空白區域，通常不會被視為留。更重要的是，物體在畫面中所處的狀態，即其空間文脈（例如，是懸浮在空中，還是穩立於地面），會顯著影響觀者對其周圍空白區域的詮釋。
