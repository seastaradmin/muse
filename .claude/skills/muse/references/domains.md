# 领域加权 / 风格相对性 / 维度交互

本文件承载三条跨维度的评审规则，评审时先读此文件，再进各维度。

## 1. 按输入类型加权

评审第一步确定输入类型，据此调整各维度的权重与默认侧重。

| 输入类型 | 高权重维度 | 说明 |
|---|---|---|
| UI 界面 / 网页 | 视觉层级、对比/色彩、留白、排版 | 信息密度高，层级与可读性是命脉；构图走"功能型界面豁免"，求稳不求巧 |
| 摄影 / 画作 | 构图、色彩、留白 | 主体安排、光影、意境为主 |
| 短剧镜头 / 影视帧 | 构图、色彩、留白 | 景别、视线引导、画面氛围；影视专属维度（运镜/调色）待影视层数据补充 |
| 海报 / 平面 | 构图、排版、色彩 | 图文结合，层级与构图并重 |

> 权重只决定"重点评哪几维、给分从严从宽"，不是"跳过不评"——所有出现的维度都评，只是结论详略与打分基调不同。

## 2. 风格相对性（先立风格，再评分）

通用标准只是基线，不能当唯一标尺。评审先确立画面的**类型与风格框架**，在该框架内评分：

- 明确风格归属（极简、波普、印象派、赛博朋克、儿童插画…），尊重其流派自洽的逻辑。
- 若画面属某风格但按通用标准"不对"，要区分**"该风格内的瑕疵"**与**"风格选择本身"**——后者不是错误。
- 示例：极简界面留白多是优点不是空洞；波普高饱和冲突是风格特征不是配色失败；工具类 UI 求稳、艺术类作品求表现，用对应的尺子。

## 3. 维度交互（避免孤立评分）

各维度相互影响，评审时注意叠加关系，避免重复加分或漏判：

- 色彩 × 对比：配色是否和谐、前景/背景对比是否足够，是两回事，分开看（对比硬阈值见 color.md）。
- 留白 × 层级：留白多少同时影响"透气感"与"主次凸显"，但各自归入留白/层级维度，别重复计。
- 构图 × 空间：三分法/负空间分属构图与留白维度，别重复计。
- 排版 × 层级：字号层级既影响可读性（排版）也影响主次（层级），从两个维度各评一次。

## 依据与出处
- 本文件三条均为**评审约定**（本 skill 的打分操作规则），非美学知识结论；其中"风格相对性"是对 [composition.md](composition.md)「功能型界面豁免」的通用化推广。
